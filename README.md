# Moon Browser

Moon is a contextual, privacy-conscious browser designed around workspaces, sessions, universal search, automation, extensions, plugins, and optional AI assistance.

## Architecture

- `packages/core` — browser domain and state
- `packages/platform` — native capability contracts
- `apps/desktop` — Electron adapter
- `apps/mobile` — shared mobile boundary
- `packages/storage` — SQLite repositories and migrations
- `packages/security` and `packages/network` — isolation, privacy and filtering
- `packages/context` and `packages/intelligence` — contextual and AI features
- `ui` and `packages/ui-core` — runtime-independent interface

The Core never imports Electron. Renderer code runs with context isolation, sandboxing, no Node integration, and an explicit IPC allowlist.

## Current desktop baseline

The Electron application now provides a functional Chromium browsing surface with:

- real HTTP/HTTPS navigation and DuckDuckGo search;
- multiple tabs with create, activate and close actions;
- back, forward, reload and stop controls;
- a native Moon home page;
- isolated renderer contexts, sandboxing and an explicit IPC allowlist;
- Linux AppImage and Debian package generation.

Architecture modules for workspaces, sessions, storage, extensions and Moon Intelligence remain progressive features; their presence does not mean every future UI is connected yet.

## Development

Requirements are Node.js 22+, npm 10+, and the native build toolchain required by `better-sqlite3`. Install dependencies only after reviewing the lockfile generated by npm.

```bash
npm install
npm run dev:desktop
```

Quality checks:

```bash
npm run typecheck
npm run lint
npm test
npm run build:desktop
```

Generated Linux packages are written to `release/`. Private user data, databases, secrets, and generated builds must not be committed.
